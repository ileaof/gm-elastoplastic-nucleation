# Elasto-plastic models

Copies of the nucleation models (elastic Gurtin–Murdoch surface) with the **elasto-plastic** Gurtin–Murdoch surface,
and copies of the SDAS (MRB) models with the elastic 1st- and 2nd-order Gibbs–Thomson tensor (as in the original) and
the elasto-plastic 2nd-order one. **The original files (`Sim Luane Final/`) were not changed**: the tools only read them.
Portuguese version: `README.md`.

Complete formulation: paper in `paper/` (Word file in `OneDrive/Documentos/Paper Nucleation/
Manuscript_ElastoPlastic_Surface_NonEquilibrium_Nucleation_v2.docx`). To take over the work, see `HANDOFF.en.md`.

## Elasto-plastic surface (`nucleacao/gm_elastoplastic.py`)

The module replaces `sigma_func`, `gamma_func_r` and `dgammadr_func_r` in the main loop: areal yield of the excess
stress s = |σ₀|·E_A^e, |s| ≤ σ_y + Hα (return mapping, r decreasing from r_eq). The yield point marks **where the
elastic range ends and the plastic range begins** (560–925 K/m in the three alloys).

**Adopted surface energy (`stored_total` mode, default of the copies, author's decision on 2026-10-22):** the
permanent deformation complements the elastic one, its energy is stored in the interface and only the heat
dissipated by the plastic flow leaves it; the equilibrium reference does not change (fixed r_eq):

    γ_SL = γ₀·(r_eq/r)² + |σ₀|·(|E_A^e| + |E_A^p|) − q_diss = γ_SL,elastic − σ_y·α        (H = 0)

The elasto-plastic Γ therefore follows the elastic one, grows in the same way with ∇T and stays above the
equilibrium value γ₀/|ΔS_V| (stored energy available for deformation-induced nucleation).
Derivative: ∂γ/∂r = −2γ₀r_eq²/r³ − (|σ₀| − σ_y)·∂E_A/∂r after yielding (H = 0).

Other modes (comparison): `complement` (updated reference r_eq,p = r_eq·exp(E_A^p/2); Γ up to 29 % lower at
8×10⁴ K/m), `barrier` (+w_p), `stored` (elastic part only), `thermo`, `restored`, `restored_barrier`.

Settings (environment variables): `GM_SURFACE_MODEL` (`elastic` | `elastoplastic`), `GM_SIGMA_YA0`, `GM_H_A`
(default 0), `GM_DISSIPATION_MODE` (default `stored_total`), `GM_PLASTIC_REFERENCE` (default 0 for `stored_total`,
1 otherwise), `GM_DT_MAX` (default 30 K: the sweep covers the whole range, up to ~10⁶ K/m).

Other changes in the copies:

* closed-form ΔT, ΔT = 2γ/(r|ΔS_V|) (the root of `f_DT` of the originals); ∇T = ΔT/(8πr). The originals'
  `brentq(f_DT, 0.0001, 1)` only finds ΔT ≤ 1 K: this is why the original script does not reach 10⁵ K/m
  (ΔT ≈ 5 K). In the copies, elastic and elasto-plastic both reach ~1.1×10⁶ K/m (end: root of the 2nd-order angle);
* sweep up to ΔT = `GM_DT_MAX`, arrays with 400 positions; 1st-order θ is NaN when it has no root;
* index `j` of the experimental gradient found in the sweep; CSV names carry the surface model;
* `*_dev_gam`: metric form of the original, 3γ₀/(1 + 2r²/r_eq²);
* rate figure against ΔT (kept) with automatic axes, the elastic curve of the same script and the yield; in all
  figures, texts and legends that left the axes are moved inside (`figure_layout.py`). The rate expression,
  exp(+ΔG*/ΔG*_ref), is unchanged;
* **new figures against ∇T over the whole range (log, up to ~10⁶ K/m)**, generated by the script itself: nucleation
  rate, 2nd-order Γ, surface energy γ and surface tension τ, each with the elastic curve of the same script
  (`figure_layout.elastic_rate`, separate process), the yield, the mean experimental ∇T and the values at 10⁵ K/m
  (`figure_layout.vs_gradient_figure`).

### Verification

* `GM_SURFACE_MODEL=elastic`: every copy reproduces its original **exactly** (`verificar_copias_elasticas.py` →
  `verificacao_elastica.txt`);
* analytical derivative of `stored_total` vs finite differences: 3×10⁻⁶; without q_diss, equal to the elastic one to
  2.5×10⁻¹⁶.

## σ_y per alloy

`ferramentas/sigma_y_ligas.txt`: 0.0386 (Al-Cu-Nb-Fe), 0.1572 (Al-Si-Mg-Fe), 0.0423 (Al-Cu-Mg-Fe), 0.0695 N/m (H₂O,
provisional). They come from an old fit (`barrier` mode, `ajustar_sigma_y.py`); in `stored_total` mode they are not a
fit to the SDAS. Since q_diss = σ_y·α vanishes for σ_y → 0 and σ_y → ∞, the deviation from the elastic Γ is largest
at intermediate σ_y.

### Elastic restoration driven by the rate of density change (Al-3Cu-5Nb-0.1Fe)

Only the elastic (recoverable) part is restored; the energy of the permanent deformation stays
(`ferramentas/ajustar_restauracao.py`):

    ε̇_v = β_s·Ṫ/ΔT_SL,   β_s = (ρ_S − ρ_L)/ρ_S = 0.0767,   Ṫ = ∇T_L(P)·V_L(P)
    ΔT_SL = 1/(90 − 5)·∫₅⁹⁰ Ṫ(P)·t_SL(P) dP = 185.3 K   (mean integral over the measured range)
    f = ε̇_v·τ_r/(1 + ε̇_v·τ_r),   Γ(P) = Γ_EP(∇T_L) − f·|s|/|ΔS_V|,   |s| ≤ σ_y

Without a defined τ_r, f = 1 is used (largest elastic restoration; `RESTORATION_TAU` sets τ_r in s). The largest
reduction is σ_y/|ΔS_V| = 3.94e-8 m K (2–10 % of Γ); Γ stays 1.2–6.3 times the equilibrium value along the casting.
The grey curve of Fig. 1 of the `Al3Cu5Nb01Fe_..._EP` copy uses, like the other MRB curves, the constant Γ at the mean
gradient minus the restored elastic part (f = 1): 9.30·t_SL^0.379 µm. (A version with the local point-to-point Γ lay
above the points at high gradients and was judged wrong by the author.)

## Unconverted file

`Nucleation_model_FCC_A1_new_paper_proposal_luana_GL_data_indev.py` has another structure: it computes r_hom by
solving `func_r_new` for a given gradient (with the elastic surface inside that function) and stops at `quit()`
before the loop. Applying the elasto-plastic surface would require rewriting `func_r_new`; the copy is in
`nucleacao/nao_convertidos/` unchanged.

## Note on an original table

In `..._Sim_Luane.py`, the header of `tabela_paper.csv` has 10 labels and the rows have 11 values (the `GT_het` label
is missing): the column labelled `GT_het_2nd` holds `GT_het_v` and the 2nd-order Γ is the last column. The extraction
in `rodar_modelos_EP.py` takes this into account; the original script was not changed.

## How to run

```bash
cd ferramentas
python aplicar_elastoplastico.py        # rebuilds the nucleation copies (ENERGY_MODE, reads sigma_y_ligas.txt)
python verificar_copias_elasticas.py <temporary folder>   # elastic mode vs original
python rodar_modelos_EP.py              # elasto-plastic runs and 2nd-order Γ (--extract only extracts)
python ajustar_restauracao.py           # elastic restoration (Al-Cu-Nb-Fe), before aplicar_sdas.py
python aplicar_sdas.py                  # rebuilds the SDAS copies
python rodar_sdas_EP.py                 # SDAS figures
python comparar_taxa_nucleacao.py       # nucleation rate: elastic vs elasto-plastic
python comparar_curvas_EP.py            # other curves against ∇T
python energia_superficie_alto_gradiente.py   # γ up to 10⁶ K/m, values at 10⁵ K/m
python gibbs_thomson_alto_gradiente.py        # Γ²ⁿᵈ up to 10⁶ K/m, values at 10⁵ K/m
```

A single model, for instance with another σ_y or in elastic mode:

```bash
cd nucleacao
GM_SIGMA_YA0=0.05 python Nucleation_model_..._EP.py
GM_SURFACE_MODEL=elastic python Nucleation_model_..._EP.py
```
